# Código Caos 🏥

Party game cooperativo 2D estilo *Overcooked*, ambientado en un hospital. 1–4 jugadores locales (teclado ×2 + mandos). Hecho con Phaser 4 + TypeScript + Vite.

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck && npm test && npm run build
```

## Estado
Proyecto base + diseño completos. **Las mecánicas y niveles están solo diseñados, no implementados.**
